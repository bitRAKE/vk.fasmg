; Every picture in the game, whatever its source. One a line:
;
;	sheet	<alias> <file>				a sheet of ideas; the file's name may hold spaces
;	cut	<name> <alias> x y width height size	lifted from a sheet into <name>.png beside this file
;	made	<name> <generator> width height		computed on the device: `made` in pictures.slang
;	drawn	<name> width height			rasterized on the device from the strokes that follow
;	  line	x y x y radius color			a capsule
;	  disc	x y radius color
;	  ring	x y radius width color
;
; then any of: flip (cut only: mirror it left to right), light (cut only: pack
; a plane of normals with it, so it is lit from one side however it turns),
; glow (light rather than matter: its halo adds to what is behind it),
; symmetric (the same mirrored left to right, which the device checks).
;
; A cut's rectangle is roughly its cell in the sheet, in the sheet's pixels; it
; may take in the cell's frame. `size` is the longer side of the result, or 0
; for the sheet's own. Stroke coordinates are texels from the frame's top left;
; a color is AABBGGRR.
;
; cut-art.ps1 reads the sheets, which live outside the repository, and writes
; the PNGs, which are committed. The build packs the PNGs and this table.
